# Forge & Fabric — Industrial Apparel Manufacturing ERP/MES

Forge & Fabric is an industrial-grade enterprise ERP/MES built for garment and apparel manufacturing facilities (jeans, knitwear, woven tops, activewear).

**Full project documentation — architecture, roles, database schema, every module, every implemented requirement, known gaps, and how to extend it — lives in a single file: [`PROJECT_REFERENCE.md`](./PROJECT_REFERENCE.md).** Start there.

## Quick start

```bash
npm install
npm run dev
```

See `PROJECT_REFERENCE.md` §12 for environment variables, build/lint commands, and database migration instructions.
